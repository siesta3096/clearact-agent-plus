# 🧀 地下室奶酪失踪案

> 王历九百四十七年 · 一部中世纪幽默侦探小品（纯离线网页视觉小说）

丰收节的前夜，城堡地下室里那块叫“月光金轮”的大奶酪失踪了。
你是被紧急征召的“大侦探”，在胖猫、弄臣、面包师之间抽丝剥茧——
放心，全程无恐怖元素，只有奶酪、小鱼和一本正经的胡说八道。

## 运行方式

本项目无任何依赖，离线即可运行，三选一：

1. **直接双击 `index.html`**（推荐，最简单）；
2. 或用任意静态服务器，例如在项目目录执行：
   ```bash
   python -m http.server 8000
   ```
   然后浏览器打开 <http://localhost:8000>；
3. 或用 Node：`npx serve .` 后访问 <http://localhost:3000>。

## 玩法说明

- **开始新游戏**：从标题画面点击「⚔️ 开始新游戏」。
- **做选择**：每个节点底部有 1–2 个选项，点击推进剧情。
- **存档**：剧情界面右上角「💾 存档」，把当前位置存到本机。
- **读档**：回到标题画面（剧情右上角「🏰 回到标题」）后，
  点击「📜 读取存档」即可回到上次存档的节点。
- **重新开始**：结局画面或任意时刻通过标题画面重新开始；
  结局页面另有「⚔️ 重新开始」直接重开一局。

## 剧情结构

两条主线、共 **6 个不同结局**：

| 分支 | 路线 | 结局 |
| --- | --- | --- |
| A · 胖猫线 | 询问胖猫“奶油” | 猫王受审 / 地下室和平条约 / 没收风波 |
| B · 弄臣线 | 检查木桌 → 追线索 | 弄臣的忏悔 / 分奶酪外交 / 地窖奶酪图书馆 |

## 存档格式

存档保存在浏览器 `localStorage`，键名 `cheese-case-save-v1`，内容为 JSON：

```json
{ "node": "cat2", "version": "1.0", "ts": 1760000000000 }
```

若浏览器禁用 `localStorage`（个别沙箱环境），引擎会自动退回内存存储，
“存档 → 回标题 → 读档”在同一会话内依然可用。

## 测试

- **手动测试**：按“玩法说明”走一遍两条分支，并在中途存档、回标题、读档。
- **自动测试（本仓库开发时使用）**：用无头浏览器打开 `index.html`，
  依次点击「开始新游戏」与各选项，断言节点文本与结局徽章出现；
  再断言「已存档」提示、回标题后「读取存档」能还原剧情节点。

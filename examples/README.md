# 实际开发样例

[`cheese-case/`](cheese-case/) 是 2026-10-18 使用 ClearAct 开发模式和本地
`qwen/qwen3.8-27b` 模型在空目录生成的视觉小说项目。页面、样式、剧情、引擎和两份文档均来自真实工具写入，
这里按原始字节保存，没有人工补写游戏实现。

直接打开 [`cheese-case/index.html`](cheese-case/index.html) 可试玩；运行方式与模块职责见样例里的 README 和架构文档。

两次开发期间实测的状态、耗时、工具成功与失败次数，以及该样例各文件的 SHA-256 见
[`2026-10-18-development.json`](../docs/evaluations/2026-10-18-development.json)。第一次最终仍需核对，第二次在交付反馈后完成。
这只是同一个任务的两次开发期间评估，不代表一般任务的成功率。项目文档也是模型产物，不应代替人工代码审查。

回归测试会实际遍历样例的全部结局，并验证保存、重新加载页面、读取存档以及重新开始。
该样例为后续修改提供固定项目，避免只用“写出一个文本文件”作为开发能力的证据。

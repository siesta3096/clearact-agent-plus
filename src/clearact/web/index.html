使用指南

01

先描述目标

在底部输入框用自然语言说清楚要完成什么，例如“分析 workspace 里的销售数据并生成报告”。按 Enter 发送，Shift + Enter 换行。

02

观察执行过程

ClearAct 会在对话流中逐步显示它正在做什么。点击阶段卡可以查看搜索来源、文件路径、工具状态和模型明确返回的说明。

03

接入新的能力

先从可信 MCP 服务目录或服务商官方文档获取配置；确认来源、权限和密钥要求后，打开左下角“设置”，找到 MCP Servers，把 mcpServers JSON 粘贴进去并导入。下次启动任务时，ClearAct 会自动发现这些工具。

MCP Registry官方服务注册表Official Servers官方维护的参考服务Smithery社区 MCP 服务目录Glama社区 MCP 服务目录

第三方目录中的服务并非天然可信：优先核对源代码、发布者、所需权限和密钥处理方式，再导入。

{"mcpServers":{"示例":{"command":"npx","args":["-y","你的-mcp-服务"]}}}
04

验证是否接入成功

新建一个任务说“列出我已接入的 MCP 工具并用其中一个做测试”。如果服务连接失败，运行记录会保留错误原因，不会伪装成成功。

权限怎么选？

不熟悉的 MCP 服务建议使用 Green：每次高风险操作都先确认。Yellow 适合已了解的服务，Red 只建议在你明确信任服务和任务时使用。
